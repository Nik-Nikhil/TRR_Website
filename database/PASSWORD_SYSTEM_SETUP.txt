PASSWORD MANAGEMENT SYSTEM - SETUP INSTRUCTIONS
================================================

## OVERVIEW
Implemented encrypted password management for players, admins, and superadmins using bcrypt encryption.

## DATABASE SETUP

1. Run the SQL migration in Supabase SQL Editor:
   File: database/user_passwords_table.sql
   
   This creates:
   - user_passwords table with encrypted password storage
   - Indexes for performance
   - Row Level Security policies

## PASSWORD MIGRATION (IMPORTANT!)

After setting up the database, you MUST migrate existing passwords:

1. Login as Super Admin (reyuk or nikhil)
2. Go to Super Admin Dashboard
3. Click "Password Migration" in the sidebar
4. Click "Check Status" to see current migration status
5. Click "Run Migration" to migrate all passwords

This will:
- Migrate all player passwords (default: "12345") to encrypted storage
- Migrate all admin passwords to encrypted storage
- Encrypt passwords using bcrypt (cannot be reversed)
- Safe to run multiple times (skips already migrated passwords)

## DEFAULT PASSWORDS

After migration:
- All players: "player123"
- All admins: "admin123" (or their existing password if set)

**IMPORTANT**: Players will be prompted to change their password on first login!

## FEATURES IMPLEMENTED

### 1. Password Service (src/services/passwordService.ts)
   - Encrypts passwords using bcrypt with 10 salt rounds
   - setPassword(): Create or update user password
   - verifyUserPassword(): Verify password against hash
   - changePassword(): Change password (requires old password)
   - resetPassword(): Admin function to reset passwords
   - hasPassword(): Check if user has password set

### 2. Password Change Modal (src/components/PasswordChangeModal.tsx)
   - Reusable modal component for password changes
   - Show/hide password toggle
   - Real-time validation
   - Success/error messaging
   - Supports both "change" (requires old password) and "set" (no old password) modes

### 3. Player Password Change
   - Added "Change Password" button to player profile page
   - Players can change their own password
   - Requires current password verification
   - Located: src/pages/Players/PlayerDetailPage.tsx

### 4. Admin Password Change
   - Updated AdminSettings component to use encrypted passwords
   - Admins can change their password from settings
   - Located: src/components/admin/AdminSettings.tsx

### 5. Super Admin Password Reset
   - Super admins can reset any user's password
   - No old password required (admin privilege)
   - Located: src/pages/SuperAdminDashboard.tsx (existing password reset modal)

### 6. Password Migration Tool
   - Admin interface to migrate all passwords at once
   - Shows migration status and results
   - Located: src/components/admin/PasswordMigration.tsx

### 7. First Login Password Change
   - Automatic prompt for players using default password
   - Modal appears on first login to player profile
   - Cannot be dismissed until password is changed
   - Located: src/components/FirstLoginPasswordChange.tsx

## SECURITY FEATURES

1. **Encryption**: All passwords are hashed using bcrypt before storage
2. **Salt Rounds**: 10 rounds of salting for strong encryption
3. **No Plain Text**: Passwords are never stored in plain text
4. **Verification**: Old password must be verified before changing
5. **Minimum Length**: 6 character minimum requirement

## USAGE

### For Players:
1. Login to your account
2. **First Login**: You will be automatically prompted to change password
   - Enter current password: "player123"
   - Enter new password (min 6 characters)
   - Confirm new password
   - Click "Change Password Now"
3. **Subsequent Logins**: Go to your profile page
4. Click "Change Password" button
5. Enter current password
6. Enter new password (min 6 characters)
7. Confirm new password
8. Click "Change Password"

### For Admins:
1. Go to Admin Dashboard
2. Click "Settings" in sidebar
3. Scroll to "Change Password" section
4. Enter current password (default: "admin123")
5. Enter new password
6. Confirm new password
7. Click "Change Password"

### For Super Admins (Reset User Password):
1. Go to Super Admin Dashboard
2. Navigate to "User Management"
3. Find the user
4. Click the key icon to reset password
5. Enter new password
6. Confirm

## TROUBLESHOOTING

If password change fails:
1. Check Supabase connection
2. Verify user_passwords table exists
3. Check browser console for errors
4. Ensure bcryptjs package is installed: npm install bcryptjs

If "Current password is incorrect" error:
1. User may not have password migrated yet
2. Run the password migration tool
3. Check if password exists in database

If migration fails:
1. Check Supabase connection
2. Verify user_passwords table exists
3. Check browser console for detailed errors
4. Try running migration again (safe to run multiple times)
